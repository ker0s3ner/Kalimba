Module map

Keep the good stuff close.

A practical map of the utilities Kalimba is designed around. Names describe intent; the ClickGUI handles the details.

BaseFinder

Scout

Scores chunks with storage, spawners, hoppers, skulls, and other player-made signals.

NewChunks

Scout

Highlights fresh terrain updates so old trails and active travel routes are easier to read.

StorageESP

Render

Makes storage and utility blocks legible while you move through a noisy world.

Waypoints

World

Save, revisit, and keep a visual breadcrumb trail for locations worth remembering.

XRay

Render

Focuses terrain reads around configured blocks with a deliberately small, inspectable target list.

Inventory Viewer

Player

Brings the inventory context you need into a compact, configurable overlay.

Server Guards

Reliability

Detects protected areas, NPC-like entities, and rejected mining actions so automation can back off.

HUD + ClickGUI

Interface

Keep the essentials visible, tune spacing and scale, and make the client feel like your own instrument.
