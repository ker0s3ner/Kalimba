Install from source

Kalimba is a Fabric-based Kotlin client. Use the repository’s Gradle wrapper and the JDK version documented in the root README.

./gradlew build

The built jar lands in build/libs/. For the theme layer, run the Vite build in src-theme/.

cd src-theme && npm ci && npm run build

Project layout

  • src/main/kotlin/ — the client and its modules.
  • src-theme/ — Svelte UI, shared tokens, and HUD components.
  • src/modules/ — the small utility prototype layer and its browser-safe harness.
  • docs/ — this GitHub Pages site.

A clean base-hunting loop

  1. Use NewChunks and travel patterns to narrow the search.
  2. Let BaseFinder score storage, spawners, hoppers, and skulls.
  3. Confirm with StorageESP, XRay, and terrain context.
  4. Drop a waypoint, record the route, and keep the rest of the HUD quiet.

Server-aware behavior

Kalimba’s guards are there to reduce wasted actions and avoid noisy retries. PvP helpers skip invulnerable or non-player targets and pause in detected no-PvP zones. Mining helpers back off after repeated server-side block restores.

These are reliability features, not guarantees. Server rules change; verify behavior on the server you are playing on and keep risky modules off unless you understand the consequences.
