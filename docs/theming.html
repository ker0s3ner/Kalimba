Theme system

Walnut, amber, signal.

The theme is built around the shape of a kalimba: warm wood, bright tines, and a small amount of resonance. The same tokens carry from the start menu into ClickGUI and HUD.

Core tokensSurfacesComponents

Core tokens

Start with the foundation in src-theme/src/colors.scss. Change the foundation first; component tokens inherit from it.

:root { --surface-color: #1e130b; --text-color: #f3e6d0; --accent-color: #d9923b; --success-color: #8fae5a; }

Surfaces that feel grounded

Use the surface color for depth, not decoration. Menus and panels use translucent mixes of the same walnut base, with the amber accent reserved for focus, selection, and action.

Walnut

#1e130b

Quiet foundation for screens and panels.

Amber

#d9923b

Focus, selection, and the path forward.

Moss

#8fae5a

Positive state without neon noise.

Component rules

  • Keep primary actions amber and secondary actions transparent.
  • Prefer one strong accent per surface.
  • Use dimmed text for metadata, never for essential controls.
  • Let the HUD disappear into the world until it has something useful to say.
